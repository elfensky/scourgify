<objective>
Build the classify verb — the highest-stakes UI in the phase — on the rails the tracer proved:
a scope step on `classify.scope_options`' fixed slots, a PLAN job that resolves the todo set ONCE,
an engine picker whose buttons carry the real price over that exact set and ARE the run, and a

the confirmation dialog. If the cost shown is stale, computed over the wrong set, or rounded down to
zero, the "no confirmation dialogs" stance stops being honest.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| plugin → LLM provider HTTP | request bodies carry book descriptions; responses are untrusted text parsed into tags |
| stored API key → engine constructor / job description / log / artifact | a secret crossing into a persisted or displayed surface |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-09 | Information Disclosure | stored key reaching a job description, log line, failures CSV or dialog | high | mitigate | Keys travel only in the `env=` mapping handed to the constructor; every recorded reason is built through `engines.redact`, and the job description passed to `_run` names the verb and the book count only — never a key or a model argument sourced from user input. `plugin/config.py`'s masking rules are unchanged. |
| T-02-10 | Spoofing | an engine key resolved from ambient state instead of the configured source | medium | mitigate | `engines.resolve_keys(stored_keys())` is the single resolution point and the environment deliberately wins over the stored value; `os.environ` is never mutated, so two jobs and a terminal alongside cannot observe each other's keys. |
| T-02-11 | Tampering | LLM response text written into library tags | medium | mitigate | Responses go through `classify.parse_resp` against the controlled vocabulary — an out-of-vocabulary term becomes a `proposed_new` candidate for adjudication, never a written tag. This is existing behaviour; the plugin adds no second parse. |
| T-02-12 | Denial of Service | an unstoppable engine pass holding a worker thread | medium | mitigate | `Plan.run(stop=)` checks the job's abort between books and shuts the executor down without waiting; the partial proposal is saved and the footer records the cancelled outcome. |
| T-02-13 | Repudiation | a tag whose producing model is unrecorded | medium | mitigate | The in-process transport carries `engine` and `model` into the edit-log run header (pinned by plan 02-01 task 3), and the applied proposal is archived in the shared artifacts format. |
| T-02-14 | Information Disclosure | book titles rendered as rich text in the scope or engine dialog | low | mitigate | Plain-text rendering on every label and cell carrying library data (ASVS L1 V5). |
| T-02-SC | Tampering | package-manager installs | low | accept | No external package is installed by this plan (02-RESEARCH.md `## Package Legitimacy Audit`: not applicable). Any future install re-enters the package-legitimacy gate. |
