<objective>
Replicate the transport seam the tracer proved on `staleness.write` across the remaining five write
producers, and pin the property that makes the seam safe: **one producer, one ops list, two
transports**.

Purpose: WRITE-01 through WRITE-05 are all blocked on the same thing — six functions that name the
CLI subprocess writer directly, which the plugin is forbidden from reaching. This plan removes that
block for all of them at once, with a regression test proving the CLI path is unchanged.

Output: a keyword-only `write=` parameter on `wrangle.Plan.write`, `classify.apply_proposal`,
`promote.backfill`, `synopsis.Plan.run` and setup's write call, plus the dual-transport invariant
test.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller → write producer | the transport is now caller-supplied; a wrong transport writes to the wrong place |
| write producer → library | every path still funnels through the shared pre-write protocol (`_write_run`) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-06 | Tampering | the injected `write=` parameter | high | mitigate | The parameter is keyword-only with the CLI writer as its default, and `test_the_default_transport_is_still_the_cli_writer` pins that default per producer; a caller that supplies nothing cannot silently land on a different transport. |
| T-02-07 | Tampering | a producer whose ops list differs per transport | high | mitigate | `test_every_write_producer_emits_one_ops_list_for_both_transports` compares the captured ops element-for-element, including each `expected` mapping — a transport-dependent decision is red, not a surprise in production. |
| T-02-08 | Elevation of Privilege | the seam accepting an arbitrary callable | low | accept | The parameter is an in-process Python callable supplied by first-party code in the same process; there is no deserialization boundary and no untrusted caller (single-user desktop app, ASVS L1 V4 not applicable). |
| T-02-SC | Tampering | package-manager installs | low | accept | No external package is installed by this plan (02-RESEARCH.md `## Package Legitimacy Audit`: not applicable). Any future install re-enters the package-legitimacy gate. |
</threat_model>
