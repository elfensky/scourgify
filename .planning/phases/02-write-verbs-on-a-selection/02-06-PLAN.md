<objective>
Turn the synopsis pass into a menu verb: settle the descriptions of the selected books with a usable
engine, refuse to start while FanFicFare would overwrite the result unless the user explicitly
accepts the degraded mode, and review each generated description before it is written.

Purpose: this pass writes into the field Calibre and every reader display, over prose an author
wrote. The whole design premise is that a good blurb is kept untouched; the review gate (D-13) is how
that premise survives contact with a GUI that could otherwise apply a batch in one click.

Output: `job_plan_synopsis` / `job_execute_synopsis`, a progress and abort seam on
`synopsis.Plan.run`, the FanFicFare guard rendered as a refusal with an explicit degraded-mode
choice, and the live `Settle descriptions` slot.
</objective>
