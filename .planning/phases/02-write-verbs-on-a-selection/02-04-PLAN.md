<objective>
Land D-03 — review items become `(label, payload)` pairs at every decision seam in the core — close
the last two `decide=` gaps (`wrangle.Plan.step` and `synopsis.Plan.run`), and give the picker its
Review 1-by-1 control.

Purpose: CLAUDE.md's standing rule is that every stage proposing a list offers a 1-by-1 review, and
that the wizard ASKS while the tool modules DO. A Qt picker can only honour that rule if the review
items carry structured data — a book id, a field, a before and an after — instead of a rich-markup
string it would have to parse. This is the change that makes the picker's before → after row
possible for every verb at once, and it is the shape Phase 4's History and Phase 5's review panel
will read.

Output: `(label, payload)` at seven decision seams, `ui.checklist` as the one place the shape is
normalized, `decide=` on the two functions that lacked it, and the picker's tick-list.
</objective>

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-02-16 | Information Disclosure | untrusted title/description text in a Qt table cell | low | mitigate | Plain-text rendering on every cell (ASVS L1 V5). |
| T-02-17 | Repudiation | a rejected item leaving no record | medium | mitigate | The existing reject logging paths are untouched by the shape change — the payload's `kind`/`class` keys are read from the same place the reject row is built, so the two cannot drift. |
| T-02-SC | Tampering | package-manager installs | low | accept | No external package is installed by this plan (02-RESEARCH.md `## Package Legitimacy Audit`: not applicable). Any future install re-enters the package-legitimacy gate. |
