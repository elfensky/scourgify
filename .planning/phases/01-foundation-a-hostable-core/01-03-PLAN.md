<objective>
Give the bundled read-only data a resource seam, so the core reads its own defaults whether it runs
from an installed wheel or from inside the plugin zip — and make the apple engine cleanly absent
off macOS.

Purpose: inside the zip, `common.HERE` is a zip-internal path, so `os.path.exists()` is False for
every bundled CSV. `load_maps()` already fails closed on that (found in plugin phase 4), which is
why the plugin is read-only today; `load_vocab()` does not, and would silently hand the classifier
an empty controlled vocabulary. `engines.Apple` independently builds its command off the same raw
constant, which is a third failure mode with a different symptom. One resolver closes all three.
The apple platform trait rides along because it is the same neighbourhood: whether the on-device
engine can run here at all.

Output: `common.defaults_dir()`, three repointed consumers, a `platforms` trait row, and a test that
builds a real zip and proves the cost estimate is identical either way.
</objective>
