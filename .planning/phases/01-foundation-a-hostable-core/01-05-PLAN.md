<objective>
Move the wizard's already-pure option and decision computations into the tool modules that own the
domain, and give every review checklist the same injectable-callback seam the write path already
has.

Purpose: phase 2 splits every verb into a PLAN job, a Qt picker that makes no core call, and an
EXECUTE job. That split can only consume the same source the wizard consumes if the source is a
pure function in a tool module rather than a private helper inside the interactive shell. The
`decide=` seam is the other half: the PLAN job passes a callback that records the items and answers
"skip", the EXECUTE job passes one that replays the picker's ticks — and the wizard keeps passing
nothing at all.

Output: six functions with new homes, seven call sites with a `decide=` parameter, `wizard.py` as a
pure consumer, and `tests/test_wizard_flow.py` and `tests/test_cli.py` still passing byte-unchanged.
</objective>
